# Hide Steam Playtime (Millennium theme)

This is a minimalistic Millennium theme that has the sole purpose to: hide your playtime from yourself.

# Why?
In some ways, I was using total and per-game playtime in non-healthy ways, such as:
- determine a "fair price" for a game based on hours played
- constant need to increase playtime, because I already paid for the game

Maybe someone else find this useful as well :)

## Manual Installation
1. Install Millennium.
2. Download this repository
3. Move `HidePlaytime` folder onto `\Steam\millennium\themes\`
4. On Millennium settings, add this theme

## Features
- Hides total playtime hours on game library pages.
- Minimizes or hides play session tracking where possible.
- Ultra-minimalistic and lightweight, probably highly compatible with future Steam updates

Built for the [Millennium](https://steambrew.app) ecosystem.
